# AGENA IAOP Agent BFF — End-to-End (E2E) Journey Matrix

This matrix documents the 10 critical end-to-end agent journeys, their required dependencies, test implementation status, and blockers.

| Journey # | Journey Name | Scenario | Downstream Dependencies | Test Implementation | Test Execution | Evidence | E2E Status |
|---|---|---|---|---|---|---|---|

| **Journey 2** | Workspace Selection → Permission Refresh | Agent selects a secondary agency workspace via `/api/v1/me/workspaces/select`; session context updates atomically | Session Store + Agency Service | Integration test suite (`main.rs`) | Executed | `mutating_request_with_valid_csrf_succeeds` | **VERIFIED** |
| **Journey 3** | Candidate → Recruitment → Onboarding | Agent refers candidate via `/api/v1/recruitment/candidates`, tracks referral via `/api/v1/recruitment/my-referrals` | Recruitment Service | BFF Routes & DTOs Verified | Local Simulation | Recruitment routes return valid FE envelopes | **BLOCKED_BY_DOMAIN_SERVICE** (`iaop-recruitment-service` is scaffold-only) |
